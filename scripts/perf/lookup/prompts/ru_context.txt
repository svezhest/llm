worker.py — точка входа (`uv run python worker.py`, launchd) и фасад:
`import worker` отдаёт любое имя пакета (живое значение из его модуля), а
setattr(worker, NAME, v) / monkeypatch.setattr(worker, ...) переставляет NAME
во всех модулях, где он связан (дом + копии `from .x import NAME`, все — один
объект). Тесты и скрипты не менялись. tests/test_facade.py проверяет, что для
каждого имени пакета патч через worker доходит до каждого читателя, что
переписываемые имена живут в одном модуле и что все worker.NAME / W.NAME из
тестов и scripts/ разрешаются.
